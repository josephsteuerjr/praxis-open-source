# praxis-hands — компилируемый пол её рук

Питон (`workshop.py`) — её **пальцы**: она правит их сама, растит эргономику, ошибается
и чинит. Этот бинарь — **пол под ними**: разрешение путей, зоны записи,
тайм-ауты, потолки вывода, гард от случайного усечения, расписка о каждой операции.
Пол не двигается оттого, что пальцы переписали сами себя.

Одна семантика — две реализации. Бинаря нет → мастерская работает ровно как раньше
(питоновый путь). Расхождение между ними ловят тесты `test_hands.py`.

## Собрать

```bash
# локально (Windows/Linux/macOS) — для разработки и тестов
cargo build --release            # → target/release/praxis-hands[.exe]
cargo test --release             # рельсы проверяет компилятор и юнит-тесты

# статический Linux-бинарь для сервера (musl, ничего не тянет за собой)
docker run --rm -v "$PWD":/src -w /src rust:alpine \
    sh -c 'apk add --no-cache musl-dev >/dev/null && cargo build --release'
cp target/release/praxis-hands ../bin/praxis-hands
```

Cargo на сервере не нужен: бинарь кладётся в `bin/` и едет томом вместе с кодом.

## Где его берут

`hands.py` ищет в порядке: `PRAXIS_HANDS` (путь или `off`), `bin/praxis-hands`,
`hands/target/release/praxis-hands`. `PRAXIS_HANDS=off` — честный питоновый путь.

## Рельсы генерируются, не пишутся

`src/rails.rs` собирается из питон-констант (`workshop.WRITE_ZONES`, `_SKIP_DIRS`,
`_SECRET_NAME`, `selfdev.PROTECTED_PATTERNS`):

```bash
python gen_rails.py           # перегенерировать
python gen_rails.py --check   # упасть, если устарел (то же делает тест)
```

Таблицы живут в одном источнике; пустое правило имён файлов тоже входит в отпечаток,
поэтому старый бинарь со старым secret-гардом виден как устаревший.

## Рукопожатие рельсов (v0.2)

Изменил константы в питоне — `rails.rs` перегенерился, но **бинарь на диске остался
старым**, и решения принимает он. Чтобы это не было тихим: в `rails.rs` генерится
`FINGERPRINT` (sha256 таблиц), `praxis-hands version` отдаёт его как `rails_fp`,
мост (`hands.rails_status()`) сверяет с репо. Отстал — `state_line` предупреждает,
а тест `test_binary_rails_are_current` валит гейт до пересборки. Цепочка доверия:
константы ≡ rails.rs (тест свежести) ∧ rails.rs ≡ бинарь (отпечаток) ⇒ константы ≡ бинарь.

## Команды

Ответ всегда — одна JSON-строка в stdout. Код возврата ≠ 0 только если бинарь не понял
запрос; ошибка операции живёт в поле `ok`.

| Команда | Что делает |
|---|---|
| `exec --cwd D --timeout S --cap N --shell "…"` | запуск в джейле cwd, убивает **дерево** процессов по тайм-ауту |
| `edit --file F --old-file A --new-file B [--root WT]` | ровно одно вхождение; 0 → превью, >1 → номера строк |
| `write --file F --content-file C [--overwrite] [--force]` | создание/осознанная перезапись + гард усечения (<70%) |
| `outline --file F` | скелет python-файла (классы/функции со строками) |
| `search --root D --glob "**/*.py" --literal T [--ignore-case]` | литеральный поиск (регекспы остаются питону) |
| `guard --path P --op read\|write\|floor` | вердикт рельсов без действия (тесты сверяют с питоном) |

`--base` — дом, относительно которого судят рельсы; `--receipt` — куда дописать расписку.

## Чего здесь нет и не будет

Git-операций, сети, вызовов моделей, зависимостей. Бинарь туп и твёрд — в этом вся идея.
Умное живёт в питоне, где она может это менять.
